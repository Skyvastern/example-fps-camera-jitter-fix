# Camera Jitter Fix
This project is used in my YouTube [video](https://www.youtube.com/watch?v=Odp_fTY1Ja8) to demonstrate 3 possible solutions in fixing camera jitter that we experience when using character body or any physics-based node.

### Solutions
1. Just use process?
2. Physics Interpolation
3. Match Physics Ticks with Refresh Rate

### Note
This project has implementation for `Solution 3`. Though, `Solution 2` as mentioned in the video is the recommended approach.
